# Custom C++ String Class (ADT)

A lightweight C++ implementation of a custom string class (Abstract Data Type) demonstrating manual memory management, object-oriented design, and string manipulations.

## 🛠 Features
- Safe character counting without relying on standard library helpers
- Custom string concatenation algorithm with dynamic memory allocation
- Modular class structure adhering to object-oriented programming (OOP) principles
